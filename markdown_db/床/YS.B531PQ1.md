# YS.B531PQ1 栗子派

## 产品信息

- **产品名称**: 栗子派
- **设计风格**: 现代简约 / 中古风
- **床架款式**: 齐边排骨架（胡桃色）
- **面料**: 头层牛皮（人体接触面）——优质进口头层牛皮，保留天然纹理，触感细腻舒适
- **靠包材质**: 海绵 + 丝绵 + 电绒丝填充
- **设计灵感**: 源于意式轻奢美学"少即是多"，整体造型如刚出炉的栗子派，宽厚饱满的靠包结合均匀拉点设计
- **适配床垫厚度**: 24-28cm
- **床脚高度**: 14cm
- **床身高度**: 31cm
- **靠包类型**: 整体无分段

**在售规格**: 
201x151    201x181    221x181    221x201

## 产品核心卖点

> **一句话价值塑造**: 一款美拉德中古风，整块大软包设计，慵懒舒适的品质真皮软床——栗子派。

### 一、设计——栗子派灵感
- 源于意式轻奢美学"少即是多"，整体造型如刚出炉的栗子派
- 宽厚饱满的靠包结合均匀拉点设计，如甜点表面精致纹理，自带松软暖意
- 主推**桃木褐棕**色，融合棕色沉稳与红色温暖，如被阳光烘烤过般氛围
- 契合中古风、现代简约等家居风格

### 二、面料——进口头层牛皮
- 人体接触面采用优质进口头层牛皮，经严格筛选加工，保留天然纹理
- 手感柔软，皮质细腻柔韧，无粗糙硬感
- 四季透气不闷热，越用越有味道
- 独特牛皮肌理搭配深咖色高品质软包，呈现低调奢华感

### 三、靠背——整块大软包，拉点设计
- 采用**整块大软包设计**，专为沉浸式包裹感与舒适感打造
- 靠包采用电绒丝填充，柔软蓬松，一压即陷
- 床头拉点设计将靠包分为多个独立分区，腰、背、肩部分段支撑
- 两端精细缝线处理，复刻经典意式沙发工艺细节

### 四、空间搭配
- 建议搭配同系列 **PT3023G-B 床头柜**，高雅软皮柜身与时尚马鞍拉手
- 同色系床头柜与软床风格统一，提升卧室视觉宽度与完整度
- 齐边排骨架（胡桃色）承托均匀，透气性好
