# YS.B553PQ1 抱抱

## 产品信息

- **产品名称**: 抱抱
- **设计风格**: 奶油风 / 现代简约
- **床架款式**: 齐边胡桃木色排骨架
- **面料**: 头层牛皮（人体接触面）——精选优质进口头层牛皮，坚韧耐磨，纹理均匀，触感爽滑
- **靠包材质**: 头层牛皮 + 海绵 + 丝绵（黄金填充配方）
- **设计灵感**: 温暖的拥抱——整块大软包靠背结构，仿若老友的温暖怀抱，治愈所有不开心
- **适配床垫厚度**: 24-28cm

**在售规格**: 
201x151    201x181    221x181    221x201

## 产品核心卖点

> **一句话价值塑造**: 一款带给您拥抱般温暖治愈的奶油风真皮软床——抱抱。

### 一看·设计——温暖的拥抱
- 设计灵感来自温暖的拥抱，整块大软包靠背结构，仿若老友的温暖怀抱
- 不靠夸张造型博眼球，用安静治愈的线条，让卧室看起来更有品味
- 主推色**霜绒白**，像初冬晨曦覆盖下的云朵自带暖意
- 能让卧室在视觉上显大、显通透，适配奶油风、原木风、现代简约风

### 二摸·面料——进口头层牛皮
- 精选优质进口头层牛皮，坚韧耐磨，赋予皮革表面均匀纹理和层次
- 触感柔软温润、毫无生硬感，日常接触格外舒适亲肤
- 透气不闷汗，夏天靠在靠背上也不会感到粘腻
- 色泽均匀，纹路清晰自然，保留了牛皮最真实的天然美感

### 三靠·靠背——整块大软包
- 床头采用**整块大软包**结构，内部填充海绵+丝绵
- 黄金填充配方——"七分软糯弹韧，三分强劲承托"
- 靠上去就像被云朵抱住，靠背柔软有支撑，久靠也不累
- 床头顶部**微弧造型**，像归家时躺进温暖的臂弯
- 竖向分区设计，两人同时倚靠也互不干扰

### 四搭·空间
- 配套同色系专属 **PTB3227G 床头柜**，风格统一
- 齐边胡桃木色排骨架，承托均匀透气性好
- 简约线条营造轻盈时尚的卧室空间氛围
