# YS.B556PQ4 纳福

## 产品信息

- **产品名称**: 纳福
- **系列**: 箱体床 超能装
- **设计风格**: 现代简约
- **床架款式**: 排骨架（箱体床/抽屉储物床，带气动杆）
- **面料**: 头层黄牛皮（人体接触面）
- **靠包材质**: 海绵 + 丝绵
- **设计亮点**: 床下隐藏式抽屉 + 箱体储物，齐边落地设计，小户型高效利用空间
- **适配床垫厚度**: 24-28cm
- **床脚高度**: 5cm
- **床身高度**: 31cm

**在售规格**: 
151×201cm / 181×201cm（含抽屉+气动杆+床板/不含床板多种配置）

## 产品核心卖点

> **一句话价值塑造**: 一款专为紧凑型户型设计，能塞下所有换季衣物、靠上去腰不悬空、颜值还显高级的实用软床。

### 一、设计——几何简约，小户型也显大
- 床头横向分区方格软包设计，均匀拉点形成自然内收弧面
- 偏意式极简高级感，黑白两色为低饱和度基础色
- 齐边落地设计不浪费过道空间
- 床下隐藏式抽屉，视觉干净整洁

### 二、面料——头层黄牛皮
- 使用头层黄牛皮，非普通皮面
- 皮面有自然微孔结构，透气不闷汗
- 后背透气不黏腻，不会因出汗导致皮面起皮脱色
- 即使使用几年仍保持顺滑干净

### 三、靠背——超舒适靠包
- 靠上去不会软塌塌塌腰，也不会硬邦邦硌背
- 可支撑睡前看手机、吹空调、看书等场景
- 像双臂轻轻托着后背一样舒服

### 四、收纳——抽屉+箱体，超能装
- 抽屉位置特意避开床头柜，避免"打架"
- 床箱支持有床板/无床板可选，满足换季衣物收纳
- 分区收纳：常用小物放抽屉，大件衣物放床箱
- 小户型也能高效利用空间
