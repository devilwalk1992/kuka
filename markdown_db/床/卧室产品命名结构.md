# 卧室产品（床）命名结构说明

> 文档来源：`bed_products/卧室产品的命名结构/` 中的命名规范图 + 实际产品数据分析

---

## 一、货号完整结构

```
[系列前缀].[B][型号数字][结构码][面料码]

示例：ZX.B712PQ7
       │  │ │ │  │
       │  │ │ │  └── 面料码: P=真皮
       │  │ │ └───── 结构码: Q7=齐边（智能电动/高箱等变体）
       │  │ └─────── 型号数字: 712
       │  └────────── 产品类别: B=床（Bed）
       └───────────── 系列前缀: ZX=智享系列
```

### 各段位说明

| 段位 | 说明 | 示例 |
|------|------|------|
| **系列前缀** | 2位字母，表示产品所属系列 | ZX、YS、JD、HS、ZW、BY |
| **B** | 固定字母，表示床类产品（Bed） | B |
| **型号数字** | 3-4位数字，表示具体款式编号 | 712、716、717、721 |
| **结构码** | 1位字母+1位数字，表示床体结构类型（详见第二节） | Q1、Q7、P1、FQ... |
| **面料码** | 1位字母（位于结构码之后或在结构码内体现），表示材质（详见第三节） | P、F、B |

## 三、面料材质码

> 来源：命名规范图中的"（五）面料材质及其代码"

| 代码 | 材质 | 备注 |
|------|------|------|
| **P** | 真皮 | 真正皮革材质 |
| **B** | 布 | 包含常规布和超纤布 |
| **F** | 仿皮 | 仿皮皮革类（PU皮革等） |

面料码位于产品货号的末尾。例如：
- `ZX.B712**P**Q7` → P=真皮（头层牛皮）
- `ZX.B721**F**Q1` → F=仿皮（PU皮革）

## 四、颜色代码规则

> 来源：实际产品数据分析总结

### 4.1 颜色代码前缀含义

| 前缀 | 含义 | 说明 |
|------|------|------|
| **T** 开头 | 真皮颜色代码 | 如 T250010、T250061、T250083 |
| **F** 开头 | 面料/仿皮颜色代码 | 如 F250010、F250061（常与T码搭配使用） |
| **U** 开头 | 真皮/高端材质颜色代码 | 如 U652122、U652223、U665162 |
| **W** 开头 | 特殊材质颜色代码 | 如 W784099（桃木褐棕） |
| **O** 开头 | 真皮颜色代码（较少见） | |

> T、U、O、W 开头的颜色代码均表示**真皮材质**。

### 4.2 常见颜色代码搭配格式

```
T250061/F250061   →  T码/F码配对使用
U652122/F652122-X →  U码/F码配对使用，X表示可定制/特殊版本
```

## 七、适用规则说明

> 来源：命名规范图中的"其他说明"及"软床结构规范"

1. **新老货号不追溯**：本规范从新编的货号开始应用，不追溯、不改变现有老货号。
2. **齐边结构定义**：床垫与床框两边齐平的结构。
3. **非齐边结构定义**：床垫与床框两边不齐平的软床。
4. 以上规则以发文之日起执行。
