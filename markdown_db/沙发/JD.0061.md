# JD.0061

## 产品信息

**产品名称**: JD.0061 大适界

**产品型号**: JD.0061

**产品线**: 经典系列

### 产品特点

- 网红罗马沙发造型，大直排大体量轻松驾驭大宅户型
- 独特AB版扶手设计，A版功能可多档调节+B版灵活移动扶手枕，躺靠更舒适
- 五色全皮可选，模块化设计多规格灵活组合，适配不同户型需求

### 一句话价值塑造

小红书热门罗马沙发，大直排大体量，五色全皮可选，AB版扶手设计，轻松驾驭大宅户型。

### 好看

延续小红书罗马沙发流行基因，时尚大方；大直排、大体量设计，气场十足；五色可选（沙滩白、琥珀棕、砂岩棕、星爵黑、烟墨棕），适配意式、现代、法式、中古等多种家装风格。

### 好舒适

独特AB版扶手设计——A版功能扶手支持多档位随心调节，灵活适配倚靠观影、休闲小憩；B版方正简约扶手设计搭配灵活移动扶手枕，居家各种坐姿躺姿都舒服。

### 好品质

全皮材质，质地扎实、手感细腻；海绵+丝绵填充，坐感舒适回弹好；扶手高度61cm，科学支撑手臂放松。

### 场景描述

搭配落地窗与城市景观，营造开阔通透的居住氛围。大直排布局搭配现代意式风格客厅，尽显高端生活品质。
