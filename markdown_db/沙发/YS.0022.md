# YS.0022

## 产品信息

**产品名称**: YS.0022 靠山

**产品型号**: YS.0022

**产品线**: 悦尚系列

### 产品特点

- 意式慵懒大体量落地沙发
- 通体全皮配置，触感细腻柔韧
- 三段式靠背，可调节功能靠头
- 坐垫/扶手/腰靠处羽毛填充，松软慵懒

### 一句话价值塑造

- 意式慵懒大体量落地沙发，三段式靠背+可调节靠头，羽毛填充松软Q弹

### 好看

- 意式大开张，饱满大体量
- 通体全皮配置，触感细腻柔韧
- 慵懒大气的落地造型，线条流畅饱满，质感颜值兼备
- 三种配色：墨灰色、星爵黑、松烟褐

### 好舒适

- 三段式分段靠背设计，精准贴合人体腰背曲线
- 靠头可多档调节，坐靠灵活调整
- 大坐深设计，无论躺靠都能享受沉浸式放松

### 好品质

- 通体全皮配置，触感细腻柔韧
- 坐垫/扶手/腰靠处羽毛填充，蓬松柔软不塌陷
- 落地款设计，沉稳大气
