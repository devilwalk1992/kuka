# YS.0051

## 产品信息

**产品名称**: YS.0051 琥珀

**产品型号**: YS.0051

**产品线**: 悦尚系列

### 产品特点

- 核心卖点：中古风全皮焦糖沙发
- 魅力属性一：全皮拉点方糖造型，打造中古风大气质感，坐面饱满柔软，扶手斜切式造型搭配金属装饰件
- 魅力属性二：分段式靠背承托，精准贴合腰部曲线，搭配精致缝棉工艺，靠背建筑式穿插结构
- 魅力属性三：皮布同款配置，一款五色可选，满足不同家装风格

### 一句话价值塑造

中古风全皮焦糖沙发，拉点方糖造型搭配斜切扶手金属装饰，分段式靠背承托，久坐轻松释压。
### 好看

全皮拉点方糖造型，打造中古风大气质感: - 沙发采用拉点造型，坐面饱满柔软，视觉上更显精致高级；
   - 扶手采用斜切式造型设计，搭配金属装饰件点缀，简约中带着精致细节，轻松撑起中古风家居的大气氛围。
### 好舒适

分段式靠背承托，久坐也能轻松释压: - 分段式靠背设计，精准贴合腰部曲线，拒绝久坐腰酸；
   - 搭配精致缝棉工艺，靠背饱满蓬松又不失支撑感；
   - 靠背建筑式穿插结构，线条利落简约。
### 好品质

皮布同款配置，一款多色可选: - 一款五色，皮布可选，既保留了全皮的高级质感，又兼顾了温馨的居家氛围，更好的满足不同的家装风格与使用需求。
