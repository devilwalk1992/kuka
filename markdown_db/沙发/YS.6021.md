# YS.6021

## 产品信息

**产品名称**: YS.6021 缤纷

**产品型号**: YS.6021

**产品线**: 悦尚系列

### 产品特点

- 时尚布艺款零靠墙功能沙发
- 落地零靠墙铁架，无需预留背部空间，大幅节省家居空间
- 简约大开张座面设计，整体更具体量感
- 分段式腰枕靠背，黄金人体工学承托，精准贴合肩、背、腰部曲线
- 花苞式外翻扶手，线条圆润流畅，躺卧时可充当头部靠枕
- 三色布艺面料可选，适配多种家居风格

### 一句话价值塑造

### 好舒适

分段式腰枕靠背，黄金人体工学承托: 分段腰枕结构设计，黄金人体工学承托，精准贴合肩、背、腰部曲线，兼顾支撑性与柔软度，久坐也能轻松释压。

### 好品质

落地零靠墙铁架，省空间更懂生活: 零靠墙功能设计，无需预留背部空间，大幅节省家居空间，适配小户型与多样户型；简约大开张座面设计，让沙发整体更具体量感，轻松撑起简约大气的居家氛围。
