# ZX.0018

## 产品信息

**产品名称**: ZX.0018 贝果

**产品型号**: ZX.0018

**产品线**: 智享系列

### 产品特点

- 饱满舒适三位电动前移沙发床，三个位置均可独立控制电动前移
- 62cm-111cm可移动坐深，满足多种生活场景
- 靠头填充30%羽毛，饱满慵懒包裹充分
- 宽大薄垫造型扶手，填充30%羽毛，躺靠皆舒适
- 分段式靠背设计，上背羽毛下背海绵科学配比
- 拉点设计点缀时尚外观，让沙发细节更加精美
- 优质进口头层黄牛皮胚，好用耐用实用

### 一句话价值塑造

饱满舒适三个位置都能前移的沙发床，62-111cm可移动坐深，靠头扶手30%羽毛饱满填充，拉点设计时尚外观。

### 好看

拉点设计点缀时尚外观: 饱满时尚外观，点缀精致的拉点元素，让沙发细节更加精美；62cm-111cm可移动坐深，兼顾美观舒适适用于一身。

### 好舒适

靠头扶手羽毛饱满填充，分段靠背科学承托: 靠头填充30%羽毛，饱满慵懒，包裹充分；扶手填充30%羽毛，躺靠都能有柔软体验；分段式设计靠背，上背填充30%羽毛，下背海绵支撑，科学配比更舒适。

### 好品质

优质进口头层黄牛皮胚，圣诺盟纯海绵填充: 头层牛皮（人体接触面），好用耐用实用；圣诺盟纯海绵，不添加钙粉，7D 15D绒丝科学配比。
