# ZX.0030

## 产品信息

**产品名称**: ZX.0030 声动岛

**产品型号**: ZX.0030

**产品线**: 智享系列

### 产品特点

- 语音控制+全屋智联款功能沙发
- 智能语音唤醒，一声"你好，小顾"即可唤醒沙发
- 语音助手、APP、按键多种操控方式可选
- 接入天猫精灵语音控制系统，全屋语音智联
- 搭载零靠墙功能架，横/竖厅皆适配
- 8档可调靠头，0-120°随心调节
- 五大高频场景+记忆模式，一声/键切换理想模式

### 一句话价值塑造

语音控制+全屋智联款功能沙发，智能语音唤醒舒适应声而动，8档可调靠头舒适随需调控。

### 好看

全屋语音智联，零靠墙设计: 接入天猫精灵语音控制系统，可由声串联全屋智能设备，实现全屋智联；搭载零靠墙功能架，横/竖厅皆适配。

### 好舒适

智能语音唤醒，舒适应声而动: 无需腾出双手，一声"你好，小顾"即可唤醒沙发；语音助手、APP、按键多种操控方式可选；依据日常使用场景设定五大高频场景+记忆模式，一声/键切换理想模式。

### 好品质

角度可调靠头，舒适随需调控: 8档可调靠头，0-120°随心调节，不用时自然放平，保持空间通透，使用时随需撑起，满足全家舒适需求。
